Both models completed the same five-seed planting objective. Luna was slightly faster and cheaper in this small sample; it is the next candidate for broader gameplay evaluation.

Each run made four physical requests: two actor calls and two asynchronous director reviews. All eight attempts across the two runs returned the specified official provider, valid tool output, and no retries. Provider allowlists contain one upstream each, fallback is disabled, and missing or mismatched response attribution stops a response before game control. OpenRouter remains the API routing layer; these are not direct Google/OpenAI API connections. No other inference provider was used in these trials.

Task time starts at the first director review after deterministic loading and ends at the last game action. It excludes startup and cleanup. Cost includes both actor and director requests, including discarded reviews. The short runs do not establish sustained latency, cost per hour, or warm-cache performance.

## Controlled setup and correctness

- Same existing Day 10 save, 06:00, FarmHouse; isolated objective ledgers; no overnight save between trials.
- Same objective: travel to Farm, plant five existing Parsnip Seeds on observed empty tilled soil, verify crop and seed counts.
- Same success condition: `location is Farm, plantedCrops >= 5, worldReady is true`; false initially, true at the final action.
- Same limits: 12 game controls, six logical actor calls, director interval four, 600 output tokens, low reasoning, required tool choice.
- Both actors selected `go_to_location`, then one `plant_seeds` batch. The local batch executed 11 normal controls without more model calls and verified each tile plus a one-seed decrement.
- Seeds 20 → 15; planted crops 0 → 5; health 100, stamina 135, money 5, and all other inventory counts unchanged. Soil was already watered; these trials do not validate watering controls.
- Both background director reviews per run were discarded after state changed or the objective completed. No synchronous director wait blocked these tasks.
- Zero model calls before world loading. Both owned game processes stopped normally.

The previous GLM isolated trial took 20.215 s and cost $0.002178 for the same planting goal. That historical result was not rerun: the current trials used only Google and OpenAI upstreams. One short trial per model is insufficient to change the default or claim general gameplay competence. Existing gaps remain: watering, tilling, return/sleep/day transitions, recovery, and reliable video. Actor calls still freeze the simulation for several seconds, so successful planting does not establish stream readiness.
